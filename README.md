# Blinkit Sales & Delivery Analysis

## Overview
End-to-end data analysis project on Blinkit order data using SQL and Power BI to uncover sales trends, delivery performance, and product insights.

## Dataset
Source: [Blinkit Sales Dataset – Kaggle](https://www.kaggle.com/datasets/akxiit/blinkit-sales-dataset)

## Tools Used
- MySQL (SQL: joins, aggregations, group by)
- Power BI (interactive dashboard)

## Key Insights
- Analyzed 2,200+ orders with total revenue of ₹11.01M
- Delivery performance split across On Time, Significantly Delayed, and Slightly Delayed orders
- Top-selling products by quantity include Baby Wipes, Bread, and Pain Reliever
- Revenue distribution analyzed across payment methods (Cash, Card, UPI, Wallet) and store locations

## Files
- `queries.sql` – SQL analysis queries (joins, aggregations, group by)
- Dashboard screenshot – Power BI visualization
